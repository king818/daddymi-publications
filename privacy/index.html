本网站由谁运营

本网站 daddymi777.com 由 米老爸 Daddy Mi（Daddy Mi 工作室）运营。如对本政策或您的个人信息有任何疑问，请联系 support@daddymi777.com。

本网站收集什么

本网站收集的个人信息仅有您在订阅表单中选择提交的电子邮箱地址。本网站不追踪您的浏览，我们也不会出售、出租或与任何人分享您的邮箱地址。

我们如何使用您的邮箱

您的订阅邮箱仅用于向您发送我们的更新——米老爸 Daddy Mi 的新歌、视频与灵修内容——不作其他用途。您可以随时退订。

删除您的信息

如需删除您的订阅邮箱，只需写信至 support@daddymi777.com，我们会将其移除。我们不持有其他个人信息，因为我们从未收集。

我们的发布工具与 YouTube API

米老爸 Daddy Mi 工作室在自己的 YouTube 频道 米老爸 Daddy Mi 上发布自己的视频与音乐。为此，工作室使用一套内部软件工具 Daddy Mi Publishing Pipeline（米老爸发布管线）；它仅在工作室自己的电脑上运行，仅由工作室自己使用。
该工具以工作室自己的 Google 账号（OAuth 2.0）登录，仅使用 YouTube Data API 发布和管理工作室自己频道上的原创内容——上传视频、字幕、播放列表条目与缩图，并核对发布状态。该工具不访问、不收集、不存储任何第三方用户的个人数据，也不与任何人分享任何信息。它仅保留工作室自身上传的操作记录（如视频 ID、标题与发布状态），存储在工作室自己的电脑上。

本政策的变更

如本政策有变更，更新后的文本将发布在本页，并标注新的生效日期。
