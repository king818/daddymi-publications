公開ツールと YouTube API について

米老爸 Daddy Mi スタジオは、自身の YouTube チャンネル 米老爸 Daddy Mi で自らの動画と音楽を公開しています。そのために、スタジオ内部のソフトウェアツール Daddy Mi Publishing Pipeline を使用しています。このツールはスタジオ自身のコンピュータ上でのみ動作し、スタジオ自身だけが使用します。
このツールはスタジオ自身の Google アカウント（OAuth 2.0）でサインインし、YouTube Data API を使って、自身のチャンネルにある自身のオリジナルコンテンツの公開と管理のみを行います（動画、字幕、プレイリスト項目、サムネイルのアップロードと、公開状況の確認）。このツールは、第三者のユーザーの個人データにアクセス、収集、保存することはなく、いかなる情報も誰とも共有しません。保持するのは、スタジオ自身のアップロードに関する運用記録（動画 ID、タイトル、公開状況など）のみで、スタジオ自身のコンピュータに保存されます。
