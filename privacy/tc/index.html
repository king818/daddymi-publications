本網站收集什麼

本網站收集的個人資訊僅有您在訂閱表單中選擇提交的電子郵件地址。本網站不追蹤您的瀏覽，我們也不會出售、出租或與任何人分享您的電子郵件地址。

我們如何使用您的電子郵件

您的訂閱電子郵件僅用於向您寄送我們的更新——米老爸 Daddy Mi 的新歌、影片與靈修內容——不作其他用途。您可以隨時取消訂閱。

刪除您的資訊

如需刪除您的訂閱電子郵件，只需寫信至 support@daddymi777.com，我們會將其移除。我們不持有其他個人資訊，因為我們從未收集。

我們的發布工具與 YouTube API

米老爸 Daddy Mi 工作室在自己的 YouTube 頻道 米老爸 Daddy Mi 上發布自己的影片與音樂。為此，工作室使用一套內部軟體工具 Daddy Mi Publishing Pipeline（米老爸發布管線）；它僅在工作室自己的電腦上運行，僅由工作室自己使用。
該工具以工作室自己的 Google 帳號（OAuth 2.0）登入，僅使用 YouTube Data API 發布和管理工作室自己頻道上的原創內容——上傳影片、字幕、播放清單條目與縮圖，並核對發布狀態。該工具不存取、不收集、不儲存任何第三方使用者的個人資料，也不與任何人分享任何資訊。它僅保留工作室自身上傳的操作記錄（如影片 ID、標題與發布狀態），儲存在工作室自己的電腦上。

本政策的變更

如本政策有變更，更新後的文本將發布在本頁，並標註新的生效日期。
